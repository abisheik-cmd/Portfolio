# Asset sources

## Original portfolio media

The four files in `client/public/media/` are the original uploads supplied by ABIZK and are mapped in `client/src/components/portfolio/portfolioAssets.ts`:

- `abizk-profile.jpeg` — profile photo
- `poster-01-leofarewell.webp` — first poster design
- `poster-02-messi.webp` — second poster design
- `featured-video.mp4` — supplied 10-second video

No generated or unrelated stock imagery is used as ABIZK's featured work.
